ملفات البورتفوليو المعدّلة
=========================
استبدلي الملفات القديمة بالثلاثة:
- index.html
- style.css
- script.js

الصور والملفات:
- ضعي صورتك في نفس مجلد index.html باسم maysa-img.jpg
- ضعي السيرة الذاتية في نفس المجلد باسم Maysa Hamed.pdf
- أنشئي مجلد images وضعي فيه:
  smart-hospital.png
  alphabet-preview.png
إذا لم تتوفر صور المشاريع، ستظهر معاينة افتراضية بأيقونة بدل صورة مكسورة.

التعديلات:
- توحيد أسماء الكلاسات بين HTML وCSS.
- إصلاح زر تبديل اللغة مع اتجاه RTL/LTR.
- إصلاح القائمة المتنقلة والتنقل السلس والرابط النشط.
- استبدال بطاقة الخبرة الميدانية في قسم المشاريع بمشروع Alphabet A–Z.
- إضافة صور معاينة اختيارية للمشاريع مع بديل تلقائي.
- إبقاء روابط التواصل في بطاقة الاتصال وتخفيف التكرار في الفوتر.
- لا يوجد رابط معاينة مباشر لمشروع Smart Hospital لأنه لم يتم نشره بعد.
- PHP وMySQL مذكوران كخطط مستقبلية للمشروع وليسا ميزات مكتملة.
